# 작업 지시서: 웹 화면 연결 (10교시)

## 1. 목표
브라우저에서 메모를 쓰고, 보고, 고치고, 지울 수 있는 화면을 만든다.
화면은 이미 만들어 둔 API(`/memos`)를 불러서 동작한다.

## 2. 요구사항
`harness/REQUIREMENTS.md` 의 **R7** 과 **N6** 을 구현한다.

## 3. 범위
- 새로 만드는 파일: `app/static/index.html`, `app/static/app.js`, `app/static/style.css`
- 고쳐도 되는 파일: `app/main.py`(화면을 내려 주는 부분만 추가), `tests/test_memos.py`(테스트 **추가**만)
- 고치면 안 되는 것: `/memos` API 의 동작, 이미 있는 테스트의 내용

## 4. 하지 말 것
- 프레임워크나 외부 라이브러리(React, Vue, jQuery, Bootstrap, CDN 링크)를 쓰지 않는다.
- API 를 새로 만들거나 바꾸지 않는다. 화면에 필요한 것은 R1~R5 로 충분하다.
- 검색, 정렬, 페이지 나누기를 만들지 않는다.

## 5. 구현 조건
- `GET /` 는 `app/static/index.html` 을 돌려준다. `/static/…` 주소로 `app.js`, `style.css` 를 내려 준다.
- 화면 구성: 제목 입력 칸, 내용 입력 칸, 저장 버튼, 안내 문구 자리, 메모 목록. 목록의 메모마다 "수정", "삭제" 버튼.
- "수정"을 누르면 위의 입력 칸에 그 메모의 내용이 채워지고, 저장 버튼이 "수정 저장"으로 바뀐다. "수정 취소" 버튼으로 되돌릴 수 있다.
- "삭제"는 지우기 전에 한 번 묻는다.
- 저장·수정·삭제 뒤에는 목록을 다시 불러온다. (페이지 새로 고침 없이)
- 서버가 422 나 404 를 돌려주면 안내 문구 자리에 한국어 문장을 보여 준다.
- **사용자가 쓴 글(제목·내용)은 `textContent` 로 화면에 넣는다. `innerHTML` 을 쓰지 않는다.**
- HTML, 자바스크립트, CSS 파일마다 한국어 주석(파일 머리 설명 + 핵심 줄)을 단다.

## 6. 완료 조건
- [ ] `sh scripts/verify.sh` 가 "검증 통과"로 끝난다.
- [ ] `GET /` 가 200 이고 응답에 "메모장"이라는 글자가 있는지 확인하는 테스트가 있다.
- [ ] `app/static/app.js` 에 `innerHTML` 이 없다. (`grep -n innerHTML app/static/app.js` 결과가 비어 있다)
- [ ] 브라우저에서 쓰기 → 목록에 보임 → 수정 → 삭제가 모두 된다. (사람이 확인한다)
- [ ] 제목에 `<b>굵게</b>` 를 넣어 저장하면 글자 그대로 보인다. (사람이 확인한다)
