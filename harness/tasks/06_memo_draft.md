# 작업 지시서: 메모 만들기·보기 초안 (6교시)

## 1. 목표
메모를 만들고, 목록으로 보고, 한 건을 볼 수 있는 API 를 만든다.
저장소는 아직 DB 가 아니라 파이썬 메모리(딕셔너리)를 쓴다.

## 2. 요구사항
`harness/REQUIREMENTS.md` 의 **R1, R2, R3, R6** 을 구현한다.
단, R6 중 "11교시에 추가"라고 적힌 공백 규칙 두 가지는 이번에 만들지 않는다.

## 3. 범위
- 고쳐도 되는 파일: `app/main.py`, `tests/conftest.py`
- 새로 만드는 파일: `app/schemas.py`, `tests/test_memos.py`
- 고치면 안 되는 것: `tests/test_health.py`, 지금 있는 `/health`·`/hello` 의 동작

## 4. 하지 말 것
- 수정(PUT)과 삭제(DELETE)는 만들지 않는다. (9교시에 한다)
- PostgreSQL 에 연결하지 않는다. (8교시에 한다)
- 화면(HTML)을 만들지 않는다. (10교시에 한다)
- 새 패키지를 추가하지 않는다.
- 4교시에 손으로 만든 `/memos` 코드(리스트 사용, `id` 를 `len(memos) + 1` 로 정함)는 요구사항에 맞게 다시 써도 된다.

## 5. 완료 조건
- [ ] `sh scripts/verify.sh` 가 "검증 통과"로 끝난다.
- [ ] 요청·응답의 모양이 `app/schemas.py` 에 Pydantic 클래스로 정의되어 있다.
- [ ] 응답에 `id`, `title`, `content`, `created_at`, `updated_at` 이 모두 들어 있다.
- [ ] 없는 번호를 조회하면 404 와 `{"detail": "메모를 찾을 수 없습니다."}` 가 온다.
- [ ] `tests/test_memos.py` 에 R1, R2, R3, R6 각각의 테스트가 있다. (정상 경우 + 실패 경우)
- [ ] 테스트끼리 서로 영향을 주지 않는다. (테스트마다 저장소가 비워진 상태에서 시작한다)
- [ ] 모든 파일에 한국어 주석(파일 머리 설명 + 핵심 줄)이 있다.

## 6. 진행 방법
`AGENTS.md` 의 작업 절차를 따른다. 먼저 계획을 말하고, 내가 "진행"이라고 하면 구현한다.
끝나면 `AGENTS.md` 의 보고 형식으로 보고한다.
