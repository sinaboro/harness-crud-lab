# 작업 지시서: 공백 제목 버그 고치기 (11교시)

## 1. 목표
제목에 공백만 넣어도 메모가 저장되는 문제를 고친다.

## 2. 현재 상황 (사람이 직접 확인한 사실)
- `POST /memos` 에 `{"title": "   ", "content": "공백 제목"}` 을 보내면 **201** 이 오고 메모가 저장된다.
- 요구사항 R6 에 따르면 **422** 가 와야 한다.
- 이 문제를 잡아내는 테스트 두 개를 사람이 `tests/test_memos.py` 에 먼저 추가했다.
  - `test_create_memo_blank_title`
  - `test_title_is_trimmed`
- 지금 `sh scripts/verify.sh` 를 실행하면 이 두 테스트가 **실패한다.** (의도한 상태다)

## 3. 요구사항
`harness/REQUIREMENTS.md` 의 **R6** 중 아래 두 줄.
- `title` 이 공백뿐이면 422
- `title` 의 앞뒤 공백은 잘라 내고 저장한다

## 4. 범위
- 고쳐도 되는 파일: `app/schemas.py`
- 고치면 안 되는 것: **`tests/` 폴더 전체** (테스트는 사람이 이미 썼다. 한 글자도 바꾸지 않는다)

## 5. 하지 말 것
- 테스트를 고치거나 지우거나 건너뛰게 만들어서 통과시키지 않는다.
- `app/main.py` 의 함수마다 검사 코드를 넣지 않는다. 입력 규칙은 한 곳(`app/schemas.py`)에 둔다. 그래야 만들기와 고치기에 똑같이 적용된다.
- 이 버그와 관계없는 코드를 고치지 않는다.

## 6. 완료 조건
- [ ] `sh scripts/verify.sh` 가 "검증 통과"로 끝난다. 실패하던 두 테스트가 통과한다.
- [ ] 원래 통과하던 테스트가 여전히 모두 통과한다.
- [ ] `git diff --stat` 에 `app/schemas.py` 만 나타난다.

## 7. 진행 방법
1. 먼저 **원인을 설명한다.** (왜 `"   "` 가 `min_length=1` 검사를 통과했는가)
2. 고칠 방법을 말하고, 내가 "진행"이라고 하면 구현한다.
3. 끝나면 `AGENTS.md` 의 보고 형식으로 보고한다.
